# Images folder

## profile/
Put your real photo here as:
```
images/profile/avatar.jpg
```
(jpg, jpeg, png, or webp all work — just update the filename in
`sections/hero.html` if the extension is different from `.jpg`.)

A generic placeholder (`avatar.svg`, no real photo) is included so the
page still looks right until you add your own.

## sites/
Put a screenshot for each site here, named exactly after its domain:
```
images/sites/ybyboxes.com.png
images/sites/emenacpackaging.com.png
images/sites/kolaxopackaging.ae.png
...
```
Recommended size: 400×250px (or similar 16:10-ish ratio), so it fits the
browser-mockup card cleanly.

If a screenshot isn't found for a domain, the site card automatically
falls back to showing that domain's favicon instead — nothing breaks if
you only add a few screenshots at a time.
